# F1 Champion Prediction: *Predict the Grid* <sub><sup>F1 챔피언 예측: *그리드 예측*</sup></sub>

Our term project for our Machine Learning course: Formula 1 World Champion Prediction using Logistic Regression, Decision Trees, Random Forests, and Support Vector Machines.

머신 러닝 과정의 학기 프로젝트: 로지스틱 회귀, 결정 트리, 랜덤 포레스트, 지원 벡터 머신을 활용한 포뮬러 1 월드 챔피언 예측.

## Try it out on Google Colab! <sub><sup>Google Colab에서 직접 사용해 보세요!</sup></sub>

1. Download `F1_Champion_Predictions_Full_Implementation_with_Interactive_Dashboard.ipynb` from this repository and upload it to Google Colab.
2. Go to [Formula 1 World Championship on Kaggle](https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020?resource=download) and download the dataset. Extract the downloaded file if possible.
3. Upload four important CSV files: `results.csv`, `races.csv`, `drivers.csv`, and `constructors.csv` to Google Colab and save all of them on `kaggle` folder.
4. Run the notebook.
